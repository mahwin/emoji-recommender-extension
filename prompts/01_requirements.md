# 요구사항 정의 (Requirements)

## 기능 요구사항

### 벡터 기반 이모지 벡터 변환 (Supabase Vector DB 내 사전 저장)
1. Supabase Vector DB에 미리 이모지 벡터를 분석하여, 저장한다.
2. LLM 모델은 TinyBERT-4L/312H를 사용한다.

### 텍스트 기반 감정·상황·의도 분석 기능
1. 사용자가 핫키(ctrl + m)를 누르면 텍스트 분석 api가 호출된다.
2. 프론트엔드(브라우저)에서 실행 가능한 임베딩 AI 모델을 사용하여 768 차원 벡터로 변경한다.
    - 임베딩 AI 모델로는 TinyBERT-4L/312H을 사용한다.
3. 벡터값을 Supabase Edge Function에 전송한다.
3. Supabase Vector DB 내 사전 저장된 이모지 벡터와 유사도 비교를 통해 계산되고, 상위 3개의 이모지를 추천
4. 추천된 이모지가 도착하면, 추천 팝업 UI가 열린다.

## UI는 크게 3가지 뷰가 존재한다.

### 추천 팝업 UI
1. 핫키(ctrl + m) 입력 후 이모지 추천이 성공적으로 완료되면 팝업 UI가 화면 우측 하단에 등장
2. 팝업은 추천 이모지 더블 클릭이나 닫기 버튼, 다른 화면 클릭을 통해서 닫을 수 있다.
3. 추천 팝업 UI에는 추천된 이모지가 존재하며, 이모지를 더블 클릭하면 이모지가 기존 커서 위치에 복사된다. 
4. 만약 기존 커서 위치가 애매하다면 아무것도 추가되지 않는다.

### 핫키 변경 팝업 UI
1. 확장 프로그램 메인 팝업 화면에는 사용자 리뷰를 입력하는 창과 핫키(기존 : cntl + m)를 변경할 수 있는 기능이 존재한다.
2. 핫 키 변경은 핫 키 변경 키를 누르고 입력한 키보드를 기준으로 바인딩 된다.

### 리뷰 팝업 UI
1. 리뷰 작성란과 별점, 제출 버튼이 존재한다.
2. 리뷰 버튼은 입력한 내용과 별점이 채워져야 제출 버튼이 활성화된다.
3. 제출 버튼을 누르면 팝업이 닫힌다.

### 사용 횟수 기반 팝업 호출 기능
1. 이모지 추천 기능이 10회 호출되면 UI의 리뷰 페이지가 팝업으로 나타난다.
2. 만약에 리뷰를 작성한 유저면 팝업창을 띄우지 않는다.

## 비기능적 요구사항
1. 성능 - 텍스트 분석 API 호출부터 추천 팝업 open까지 0.5초를 넘지 않아야 한다.

## 사용자 스토리
- 핫키를 눌러 텍스트에 맞는 이모지를 단 한번의 더블 클릭이나 엔터로 삽입하고 싶다.
